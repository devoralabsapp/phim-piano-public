# Community code of conduct

We welcome learners and contributors of different backgrounds and experience levels. Be respectful, patient, and constructive. Discuss code and ideas without personal attacks, harassment, discrimination, threats, or publishing someone's private information.

Use English or Vietnamese when participating. Explain your reasoning, provide reproducible examples, and give credit for others' work. Do not spam, manufacture engagement, or present generated work or test results misleadingly.

This policy applies to issues, pull requests, reviews, and other project spaces on GitHub. Repository maintainers may edit/remove inappropriate content, close disruptive discussions, or restrict participation in those spaces.

For non-sensitive moderation problems, flag the relevant discussion to repository maintainers without repeating harmful content. Use GitHub's **Report abuse** tools for harassment, threats, or sensitive reports; do not publish personal details in an issue. Security vulnerabilities use the private channel in [SECURITY.md](SECURITY.md).

Maintainers should apply these expectations fairly. Participation does not guarantee acceptance of a contribution or a fixed response time.
